# SleepDock 实机验收

在 Windows x64、macOS arm64 与 Intel 上分别验收。自动测试、离线截图与交叉编译不能代替以下步骤。

- [ ] 在未安装 Go / PowerShell 依赖的目标环境解压启动，图标与原生窗口正常。
- [ ] 30 分钟等快捷项与手动时间输入正常，指定凌晨时间明确显示日期。
- [ ] 开始后显示大号倒计时，重复点击不能覆盖活动计划。
- [ ] 活动计时关闭窗口后托盘仍在；从托盘恢复窗口、延后和取消正常。
- [ ] 托盘退出或应用完整退出取消计划；重新启动不会恢复旧计划。
- [ ] 用 1 分钟计划验证到时窗口出现、系统通知与 60 秒提醒。
- [ ] 提醒期间取消不发出睡眠请求，延后正确回到计时状态。
- [ ] 无人操作时进入普通睡眠；唤醒后计划已结束，不重复睡眠。
- [ ] 计时中手动睡眠或系统提前睡眠，唤醒后该计划结束。
- [ ] 原有系统自动睡眠与熄屏计划仍生效。
- [ ] 通知权限被拒绝时仍有应用内提醒；睡眠权限或电源配置不支持时有详情与重试入口。
- [ ] 480×600、560×640、系统缩放及深浅主题下布局、输入和按钮均可操作。

托盘创建失败时，应用会显示可展开的错误提示，关闭窗口按退出处理，避免出现无法找回的后台计时。无活动计划时关闭窗口直接退出。

测试代码中的所有睡眠接口均为模拟实现，离线预览不能调用系统睡眠。
